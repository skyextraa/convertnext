# Local Windows setup

ConvertNest now runs as an MP3-only YouTube converter plus the PDF/image tools.

1. Install Python 3.11+ and Git if needed.
2. Run `setup_windows.bat`.
3. Run `start_windows.bat`.
4. Open `http://127.0.0.1:5000`.

FFmpeg is provided by the `imageio-ffmpeg` Python package, so a separate FFmpeg install is normally not required.
